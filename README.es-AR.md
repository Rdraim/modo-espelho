Definí capacidades por modo y autorizá en el servidor antes de ejecutar.

## Instalación

```bash
git clone https://github.com/Rdraim/modo-espelho.git
cd modo-espelho
npm test
node examples/basic.mjs
```

## Ejemplo ejecutable

```js
import {capacidades, permitido, exigir} from './src/index.js';
console.log(permitido({modo:'espelho',acao:'excluir',permissoes:['ler','excluir']}));
```

## API

`capacidades(modo)` devuelve una copia. `permitido({modo, acao, permissoes})` exige permiso del modo y de la identidad. `exigir(contexto)` lanza error con `code: ACESSO_NEGADO`. Modos: principal, espelho de sólo lectura y offline con borradores.

## Límites

Referencia de autorización, no motor de sincronización o backup. Obtené modo y permisos de contexto confiable del servidor, nunca del navegador. El consumidor debe proteger cada operación y revalidar borradores al reconectar.

## Compatibilidad

Núcleo sin dependencias de ejecución. CI con Node.js 22 y 24. Instalación desde Git; este proyecto no está publicado en npm. Revisá Releases y fijá una tag/commit al integrar. Actualizaciones requieren revisar licencia, engines y pruebas del consumidor. Un badge de CI no certifica seguridad.
